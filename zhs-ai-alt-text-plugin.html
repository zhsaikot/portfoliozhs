Installation & Setup Guide

Deploy in less than 2 minutes. Install directly from your WordPress admin dashboard or deploy via WP-CLI.

1
Search the Repository: In your WordPress admin, navigate to Plugins → Add New Plugin. In the search bar, type ZHS AI Alt Text Generator.
2
Install & Activate: Click Install Now on the card authored by MD. Ziaul Hasan, then click Activate.
3
Configure Provider or Start Free: Navigate to Settings → ZHS AI Alt Text. Choose your preferred AI provider (OpenAI, Gemini, Claude, Qwen) or keep the 100% Free Basic Mode. Run your first bulk alt text batch!
1
Download ZIP: Download the latest release from the official repository at wordpress.org/plugins/zhs-ai-alt-text-generator/.
2
Upload & Extract: Go to Plugins → Add New → Upload Plugin, choose the downloaded ZIP file, and click Install Now.
1
Run WP-CLI Command: Execute the one-liner command below in your WordPress root directory:
wp plugin install zhs-ai-alt-text-generator --activate
